# input 폴더

이 폴더에 원자료를 넣으세요. 파일 이름과 형식은 자유입니다 (`.md`, `.txt` 권장).
템플릿은 `templates/`에서 복사해 쓰세요: `career.md` → `input/career.md`, `project.md` → `input/project-<이름>.md`.

- 기존 이력서·경력기술서
- 프로젝트별 메모: 기간, 역할, 기술 스택, 했던 일, 결과(숫자가 있으면 좋음)
- 지원 공고(JD): `jd.md`로 저장하면 jd-matcher가 우선 사용

**개인정보(이름, 연락처, 생년월일, 주소 등)는 넣지 마세요.**
에이전트가 이 폴더를 읽습니다. 개인정보는 `.env` 또는 환경변수에 넣으면 마지막 `npm run render` 단계에서만 채워집니다.
